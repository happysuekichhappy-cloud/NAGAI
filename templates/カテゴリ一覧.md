# カテゴリ一覧

ノートのメタ情報に書く「カテゴリ」はこの中から**1つだけ**選ぶ。
迷ったら「その他」でOK。後で変えてもいい。

> ※ 命名揺れ（「リサーチ」と「商品リサーチ」が混在 等）を防ぐため、表記はここに合わせる。

## カテゴリ

| カテゴリ | こんな内容 |
|---|---|
| **リサーチ** | 商品選定、需要・供給の見極め、ライバル分析、価格相場調査 |
| **仕入れ** | 仕入れ先、仕入れ判断、回転率、ロット、輸入 |
| **出品** | 商品タイトル、説明文、写真、SEO、出品作業 |
| **価格戦略** | 値付け、値下げタイミング、手数料計算、プラットフォーム比較 |
| **顧客対応・発送** | クレーム対応、評価、梱包、発送方法、配送トラブル |
| **在庫管理** | 在庫数、保管、棚卸し、廃棄判断 |
| **ツール** | プライスター、Keepa、各種自動化ツール、Excel/スプシ術 |
| **利益計算** | 損益、キャッシュフロー、経費、税金 |
| **マインドセット** | モチベ、習慣、目標設定、メンタル管理 |
| **失敗事例** | やらかし記録、損切り、トラブル振り返り |
| **その他** | 上記に入らないもの |

## カテゴリを増やしたくなったら

勉強が進んで「このカテゴリ足りない」と思ったら、ここに追記する。
ただし**増やしすぎない**こと（増えすぎると整理が崩れる目安：10〜15個まで）。
