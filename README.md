# NAGAI 学習アウトプット

物販マネタイズプロジェクトの**勉強用アウトプット**を貯めていく場所。

動画・本・記事などを見たあとに、自分の言葉でまとめて、後で見返せるようにする。

## ディレクトリ構成

```
NAGAI/
├── README.md                 ← 今ここ（使い方ガイド）
├── notes/                    ← 書いたノートが溜まる場所
│   ├── INDEX.md              ← 全ノートの一覧
│   └── 2026-05-15-XXX.md     ← 個別ノート（日付＋タイトル）
└── templates/                ← テンプレート集
    ├── 動画ノート.md          ← メイン
    ├── 3行メモ.md             ← 時間ない時用
    └── カテゴリ一覧.md         ← カテゴリの定義
```

## 使い方の3パターン

### 1. テンプレを使って自分で書く

`templates/動画ノート.md` をコピーして `notes/YYYY-MM-DD-タイトル.md` として保存。
穴埋めしていけばOK。

Claude に頼む場合：

> 「動画ノート作って。タイトルは『メルカリのリサーチ手法』」

→ Claude が `notes/2026-05-15-メルカリのリサーチ手法.md` を作成。

### 2. 書いた後にレビューしてもらう

書いたノートを Claude に見せて：

> 「これ見て。意味わからないとこある？」
> 「整理して」

すると Claude が以下をチェック：

- **意味が通らない・あいまいな箇所の指摘**（最重要）
  - 「この方法」が何を指してるか不明、主語抜け、論理の飛び など
- 不足してそうなセクション
- **「こんな観点もアウトプットすると良い」提案**
- 既存ノートとの関連リンク

**※ Claude は勝手に書き換えない。指摘するだけ。直すのは自分。**
（自分の言葉で直すから理解が定着する）

### 3. 雑に話したものをノート化

トークで思いつくまま話した内容を貼り付けて：

> 「これをノートにして」

→ Claude がテンプレ形式に整形 + 意味不明な箇所を指摘。

## ノートを書いたあとの仕上げ

INDEX を最新にしておくと、後で見返しやすい：

> 「INDEX 更新して」

→ Claude が `notes/INDEX.md` を最新ノートを反映した状態に更新。

## カテゴリ

ノートの冒頭に**カテゴリを1つだけ**つける。
カテゴリ一覧は `templates/カテゴリ一覧.md` を参照。

例：`カテゴリ：リサーチ`

これで後で「リサーチ系のノートまとめて見たい」がすぐできる。

## 命名ルール

- ノートファイル名：`YYYY-MM-DD-短いタイトル.md`
  - 例：`2026-05-15-メルカリのリサーチ手法.md`
- 日付は視聴・学習した日

## 困ったら

- 何を書けばいいか分からない → `templates/動画ノート.md` の穴埋めをそのまま埋める
- 書く気力がない → `templates/3行メモ.md` を使う（3行だけ）
- カテゴリ迷う → `templates/カテゴリ一覧.md` を見る or 「その他」でOK
- 整理が崩れてきた → Claude に「整理して」と頼む
